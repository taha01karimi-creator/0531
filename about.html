خانه دربارهٔ نمونه‌کار

دربارهٔ این نمونه‌کار

یک فروشگاه پوشاک کامل با دادهٔ نمونه؛ ساخته‌شده برای نشان دادن طراحی رابط، تجربهٔ خرید و پیاده‌سازی فرانت‌اند و بک‌اند.

این پروژه چه چیزی را نشان می‌دهد؟

هدف، ساختن یک جریان خرید واقعی بود: از دیدن محصول و فیلتر کردن تا انتخاب سایز، سبد خرید، کد تخفیف و ثبت سفارش. همهٔ صفحه‌ها با HTML، CSS و JavaScript خالص ساخته شده‌اند و بدون هیچ فریم‌ورکی اجرا می‌شوند.

  • صفحهٔ اصلی با اسلایدر، دسته‌بندی‌ها و بخش‌های پرفروش
  • فروشگاه با فیلتر دسته، سایز، رنگ، قیمت و مرتب‌سازی
  • صفحهٔ محصول با گالری، جدول سایز و محصولات مرتبط
  • سبد خرید، کد تخفیف و ثبت سفارش نمایشی
  • دسته‌بندی‌های مردانه، زنانه و بچگانه

استک و ساختار

  • فرانت‌اند: HTML5، CSS اختصاصی، JavaScript بدون وابستگی
  • بک‌اند اختیاری: Flask، SQLite، نشست امضاشده و توکن CSRF
  • پنل مدیریت: مدیریت محصول، سفارش و تنظیمات فروشگاه
  • میزبانی نمونه: GitHub Pages به‌صورت استاتیک

نسخهٔ آنلاین فقط فرانت‌اند است؛ سبد خرید و سفارش در همان مرورگر می‌ماند و درگاه پرداخت واقعی ندارد. برای اجرای کامل، بک‌اند Flask و پنل مدیریت در مخزن قرار دارد.

طراحی

تایپوگرافی فارسی، چیدمان تحریریه‌ای، پالت خنثی با لهجهٔ شرابی و انیمیشن‌های ملایم ورود.

دسترس‌پذیری

ساختار معنایی، برچسب برای دکمه‌های آیکونی، کنتراست خوانا و پشتیبانی از کاهش حرکت.

محدودیت‌ها

پرداخت واقعی، ارسال ایمیل و ذخیرهٔ سفارش روی سرور در نسخهٔ آنلاین فعال نیست؛ این نمونه برای نمایش است.
