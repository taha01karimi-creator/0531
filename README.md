# 0531 — فروشگاه پوشاک کدلاین

نمونه‌کار فروشگاه آنلاین: صفحهٔ اصلی، فروشگاه با فیلتر و مرتب‌سازی، صفحهٔ محصول و سبد خرید.
فرانت‌اند HTML/CSS/JavaScript خالص است و همین الان روی GitHub Pages به‌صورت استاتیک کار می‌کند.

مخزن دو حالت دارد:

| حالت | چه چیزی دارد | مناسب برای |
| --- | --- | --- |
| استاتیک (پیش‌فرض) | فقط فرانت‌اند؛ دادهٔ نمونهٔ داخل `assets/js/data.js`، سبد خرید در `localStorage` | نمایش نمونه‌کار روی GitHub Pages |
| کامل | همان فرانت‌اند + بک‌اند Flask + دیتابیس SQLite + پنل مدیریت | اجرای واقعی روی سرور یا سیستم خودتان |

سایت بدون بک‌اند هم کامل کار می‌کند. اگر بک‌اند اجرا شود، همان صفحه‌ها خودکار به API وصل
می‌شوند: محصول‌ها، تنظیمات ارسال، کدهای تخفیف و ثبت سفارش از سرور می‌آیند.

## اجرای نسخهٔ کامل (بک‌اند + پنل)

```bash
cd backend
python -m venv .venv
# ویندوز:
.venv\Scripts\activate
# لینوکس/مک:
source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env     # یک رمز قوی برای ADMIN_PASSWORD بگذارید
python run.py
```

- فروشگاه: <http://127.0.0.1:5000>
- پنل مدیریت: <http://127.0.0.1:5000/admin.html>

اگر `ADMIN_PASSWORD` را در `.env` نگذارید، یک رمز تصادفی ساخته و یک‌بار در ترمینال چاپ می‌شود.
دیتابیس `backend/data/shop.db` است و محصول‌ها در اولین اجرا از `backend/data/products.json`
داخل آن ریخته می‌شوند (۳۳ محصول، ۸ دسته).

### پنل مدیریت

- ورود امن با نشست امضاشده + توکن CSRF + محدودیت تلاش ناموفق
- داشبورد: تعداد محصول، سفارش‌ها، فروش و سفارش‌های در انتظار
- محصولات: افزودن، ویرایش (قیمت، تصویر، رنگ، سایز، توضیحات) و حذف نرم
- سفارش‌ها: جستجو، فیلتر وضعیت، جزئیات و تغییر وضعیت
- تنظیمات: هزینهٔ ارسال، سقف ارسال رایگان و کدهای تخفیف

### API

| متد | مسیر | توضیح |
| --- | --- | --- |
| GET | `/api/health` | بررسی آمادگی سرویس |
| GET | `/api/products` | کاتالوگ فعال |
| GET | `/api/products/<id>` | یک محصول |
| GET | `/api/settings` | هزینهٔ ارسال و کدهای تخفیف |
| POST | `/api/orders` | ثبت سفارش (قیمت‌ها روی سرور حساب می‌شود) |
| GET | `/api/orders/track?code=...` | پیگیری سفارش |
| GET | `/api/csrf` | توکن امنیتی فرم‌های پنل |
| POST | `/api/auth/login` / `logout` | ورود و خروج مدیر |
| GET/POST/PUT/DELETE | `/api/admin/products…` | مدیریت محصول‌ها |
| GET/PUT | `/api/admin/orders…` | مدیریت سفارش‌ها |
| GET/PUT | `/api/admin/settings` | تنظیمات فروشگاه |
| GET | `/api/admin/stats` | آمار داشبورد |

### استقرار

```bash
cd backend
SHOP_ENV=production SECRET_KEY="یک-رشتهٔ-تصادفی" ADMIN_PASSWORD="..." \
  gunicorn --workers 2 --bind 0.0.0.0:8000 "app:create_app()"
```

پشت Nginx یا هر پراکسی، فایل‌های استاتیک را می‌توانید مستقیم سرو کنید و فقط `/api` را به
گانیکورن بفرستید. `SHOP_ENV=production` کوکی نشست را `Secure` می‌کند، پس حتماً روی HTTPS اجرا کنید.

### نکات امنیتی

- هیچ رمز یا کلیدی داخل کد نیست؛ `.env` و دیتابیس در `.gitignore` هستند.
- همهٔ قیمت‌ها و درصد تخفیف روی سرور محاسبه می‌شود؛ دادهٔ مرورگر فقط برای نمایش است.
- تغییرها هم‌مبدأ بودن درخواست و (برای پنل) توکن CSRF را بررسی می‌کنند.
- رمزها با scrypt هش می‌شوند و نشست مدیر ۸ ساعت اعتبار دارد.

## ساختار

```
index.html / shop.html / product.html / cart.html   صفحه‌های فروشگاه
admin.html                                          پنل مدیریت
assets/                                             css، js، تصاویر و فونت‌ها
backend/                                            API و سرور Flask
  app.py       ساخت اپ و سرو کردن همان فایل‌های استاتیک
  api.py       مسیرهای عمومی و پنل
  db.py        دیتابیس SQLite و دادهٔ اولیه
  security.py  هش رمز، CSRF، محدودیت نرخ
  data/        products.json و دیتابیس محلی
```

این سایت نمونه‌کار است؛ درگاه پرداخت واقعی ندارد و سفارش نمایشی ثبت می‌شود.
